# Dogfood session — 2026-09-23

An exploratory test of the running app (import → recategorize → budgets → monthly report),
driven through a browser against a local dev database holding only fixture data. It found ten
issues; the user found two more afterwards and a code review raised one claim. The fixes were
planned and built in [plan 05](../plans/05-dogfood-fixes.md); the wording failures went to
[plan 07](../plans/07-language-and-theme-switch.md).

Scope at the time: Sparkasse CSV-CAMT only, `fixtures/sparkasse-camt-18.csv`, and a `/budgets`
page that the UI redesign ([plan 08](../plans/08-ui-redesign.md)) later replaced with Überblick.
File names in the commits below are from before that redesign.
